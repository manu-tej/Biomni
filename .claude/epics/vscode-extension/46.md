## Overview

Optimize the VSCode extension for production deployment by implementing comprehensive build optimization, bundle analysis, tree-shaking, and performance tuning. Ensure the extension meets strict performance requirements for VSCode Marketplace submission.

## Acceptance Criteria

### ✅ Bundle Optimization
- [ ] **Bundle Size**: Final bundle size under 5MB
- [ ] **Tree Shaking**: Remove unused code and dependencies
- [ ] **Code Splitting**: Lazy load non-essential modules
- [ ] **Minification**: Optimize JavaScript and CSS assets
- [ ] **Compression**: Enable gzip/brotli compression
- [ ] **Bundle Analysis**: Generate detailed bundle analysis reports

### ✅ Performance Benchmarks
- [ ] **Startup Time**: Extension activation under 2 seconds
- [ ] **Memory Usage**: Runtime memory footprint under 100MB
- [ ] **Load Time**: Command execution response under 500ms
- [ ] **File Operations**: Large file handling without blocking UI
- [ ] **API Calls**: Efficient Biomni API communication with caching
- [ ] **CPU Usage**: Minimal background CPU consumption

### ✅ Build Configuration
- [ ] **Production Config**: Optimized webpack configuration
- [ ] **Environment Variables**: Proper production environment setup
- [ ] **Source Maps**: Generate source maps for debugging
- [ ] **Asset Optimization**: Optimize images, icons, and static assets
- [ ] **ESLint/Prettier**: Code quality and formatting validation
- [ ] **Build Scripts**: Automated production build pipeline
