## Overview

Implement core MCP (Model Context Protocol) server integration with automatic lifecycle management. This includes server auto-start/stop coordination with VSCode extension lifecycle, WebSocket communication, and robust error handling.

## Acceptance Criteria

### ✅ Core Requirements
- [ ] **MCP Server Auto-Start**: Automatically start MCP server when extension activates
- [ ] **Lifecycle Coordination**: Proper start/stop with extension activation/deactivation
- [ ] **WebSocket Communication**: Establish and maintain WebSocket connection to MCP server
- [ ] **Connection Management**: Automatic reconnection with exponential backoff
- [ ] **Error Handling**: Comprehensive error handling with user-friendly messages

## Implementation Details

### Server Lifecycle Management
```typescript
// Extension activation
export async function activate(context: vscode.ExtensionContext) {
  const mcpManager = new MCPServerManager()
  await mcpManager.start()
  context.subscriptions.push({
    dispose: () => mcpManager.stop()
  })
}
```

### WebSocket Integration
- Connection establishment with retry logic
- Heartbeat/ping-pong for connection health
- Automatic reconnection on disconnect
- Message queuing during connection interruptions

### Process Management
- Spawn MCP server as child process
- Monitor process health and restart on crashes
- Proper cleanup on extension deactivation
- Environment variable configuration

### Error Scenarios
- Server startup failures
- WebSocket connection errors
- Process crashes and recovery
- Network connectivity issues
- Port conflicts and resolution
