# Biomni VSCode Extension - Video Tutorials

## Overview

This directory contains scripts and resources for creating comprehensive video tutorials for the Biomni VSCode Extension. The tutorials are designed to provide both quick introductions and detailed walkthroughs for users of all skill levels.

## Tutorial Series

### 1. Quick Start Series (2-5 minutes each)
- **Getting Started in 2 Minutes**: Basic installation and first analysis
- **Core Features Demo**: Overview of main bioinformatics tools
- **File Format Support**: Working with FASTA, FASTQ, VCF files

### 2. Deep Dive Series (5-10 minutes each)
- **Advanced BLAST Workflows**: Database selection, parameter tuning, result interpretation
- **Sequence Analysis Pipeline**: From raw sequences to publication-ready results
- **Performance Optimization**: Making the most of large datasets

### 3. Troubleshooting Series (3-7 minutes each)
- **Common Issues and Solutions**: Resolving typical problems
- **Configuration Best Practices**: Setting up Biomni for your workflow
- **Integration with Other Tools**: Connecting to external services

## Production Notes

### Video Requirements
- **Resolution**: 1920x1080 (1080p) minimum
- **Frame Rate**: 30 fps
- **Audio**: Clear narration with no background noise
- **Captions**: All videos must include accurate closed captions
- **Duration**: Target lengths specified for each tutorial
- **Branding**: Consistent intro/outro with Biomni branding

### Recording Environment
- **VS Code Theme**: Use default dark theme for consistency
- **Font Size**: Set editor font size to 16pt for visibility
- **Cursor**: Enable cursor highlighting for screen recording
- **Window Size**: Full screen or consistent window size
- **Zoom Level**: 150% minimum for text readability

### Accessibility Features
- **Audio Description**: Key visual elements described in narration
- **High Contrast**: Compatible with high contrast mode
- **Keyboard Navigation**: All interactions shown with keyboard shortcuts
- **Screen Reader**: Considerations for screen reader users

## Script Format

Each script follows this structure:
- **Objective**: What the viewer will learn
- **Prerequisites**: Required knowledge or setup
- **Duration**: Target video length
- **Script**: Full narration with timing marks
- **Visual Cues**: Screen actions and highlights
- **Resources**: Files and links needed
- **Accessibility Notes**: Special considerations

## Production Workflow

1. **Script Review**: Technical accuracy and pedagogical clarity
2. **Resource Preparation**: Sample files, configurations, test data
3. **Recording**: Screen capture with narration
4. **Editing**: Cut, transitions, captions, branding
5. **Review**: Quality assurance and accessibility check
6. **Publishing**: Upload to platforms with metadata
7. **Analytics**: Track engagement and feedback

## Sample Files

The `sample-files/` directory contains:
- **FASTA files**: Various sequence types (DNA, RNA, protein)
- **FASTQ files**: NGS read data with different quality profiles
- **VCF files**: Variant data from different organisms
- **Configuration files**: Optimized settings for different use cases

## Platform Distribution

Videos will be available on:
- **YouTube**: Primary hosting with searchable captions
- **Vimeo**: Alternative hosting with privacy controls
- **GitHub Pages**: Embedded in documentation
- **VS Code Marketplace**: Extension page preview videos

## Maintenance Schedule
